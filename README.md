# SolNeutral V7.6.1 — Testnet Trade Lab Refinement

This release upgrades the active SolNeutral experience from a reserve-only flow into a cleaner product workspace.

## What changed

- Trade Lab now combines:
  - real wallet-owned SOL reserve actions on Solana testnet, and
  - local demo SOL trading for user interaction.
- Added a new demo trading panel for simulated long/short SOL ideas.
- Improved test SOL onboarding inside the reserve flow.
- Tightened the dashboard KPI wording and layout.
- Updated browser metadata to explicitly include the favicon.
- Renamed the side-rail Trade destination from "SOL Reserve" to "Trade Lab".

## Purpose

Users can now:
1. connect a wallet,
2. request testnet SOL,
3. deposit/withdraw real testnet SOL in a wallet-owned reserve,
4. interact with a demo trading experience without Drift setup friction.

## Important note

Demo trades are simulations only. They do not send on-chain orders or manage real positions.
